# کوردتێک | KurdTech — پلاتفۆرمی پێشکەوتووی تەکنەلۆژیای کوردستان

پلاتفۆرمێکی تەواو داینامیک و مۆدێرنی هەواڵ، پێداچوونەوە و شیکاری تەکنەلۆژیا لەسەر شێوازی **Zoomit.ir** بە زمانی شیرینی کوردی (سۆرانی)، بنیاتنراو لەسەر **Next.js 14 (App Router)**، **TypeScript**، و **Tailwind CSS**.

---

## 🚀 نەخشەی تەواوی بەشەکان (Full Platform Ecosystem)

1. **ڕێڕەوە داینامیکەکان (Dynamic App Routing):**
   - `/` — پەڕەی سەرەکی بە دیزاینی Bento Grid و فیدێکی دابەشکراوی بەشەکان
   - `/articles/[id]` — پەڕەی تەواوی بابەت بە هێڵی پێشکەوتن، پەخشی دەنگی کوردی، قەبارەی فۆنت، ئەنجامی پشکنین، خاڵە بەهێز و لاوازەکان، خشتەی تایبەتمەندییە تەکنیکییەکان و سیستەمی لێدوان
   - `/category/[slug]` — ئەرشیڤی بەشە جیاوازەکان (زیرەکی دەستکرد، مۆبایل، پێداچوونەوە، یاری، تەکنەلۆژیا لە کوردستان، زانست)
   - `/prices` — پێنوێنی نرخی ئامێرەکان لە بازاڕەکانی هەرێمی کوردستان (هەولێر، سلێمانی، دهۆک) بە دۆلار ($) و دینار (IQD) لەگەڵ حاسیبەی ئاڵوگۆڕی دراو
   - `/compare` — ئامرازی بەراوردکاری هاوشانی دوو یان سێ ئامێر بە هەموو وردەکارییەکان و نمرەی شایستەیی
   - `/advisor` — ڕاوێژکاری زیرەکی دەستکرد (AI Buying Advisor) بۆ پێشنیارکردنی باشترین مۆبایل و لاپتۆپ بەپێی بودجە و ئەولەویەت
   - `/deals` — ڕێبەری داشکاندن و ئۆفەری تایبەتی فرۆشگاکانی هەولێر، سلێمانی و دهۆک بە کۆدی داشکاندن
   - `/glossary` — فەرهەنگی دیجیتاڵیی زاراوەکانی تەکنەلۆژیا (NPU, Ray Tracing, FTTH, OLED, eSIM, LLM)
   - `/community` — کۆمەڵگەی پرسیار و وەڵامی تەکنیکی بۆ کێشەکانی تۆڕ، فایبەر، فینتێک و مۆبایل
   - `/profile` — پەڕگەی بەکارهێنەر، مێژووی خوێندنەوە، لایکەکان و ڕێکخستنی فۆنت
   - `/admin` — ستۆدیۆی نووسەران و بەڕێوەبردن (Admin Studio) بۆ بڵاوکردنەوەی ڕاستەوخۆی بابەتی نوێ
   - `/saved` — لیستی بابەتە پاشەکەوتکراوەکان (Reading List)

2. **سیستەمی کارلێککار و دۆخ (Interactive State & Context):**
   - **داشکاندن و پرۆمۆ کۆد (Deals & Promo Codes):** کۆپیکردنی ڕاستەوخۆی کۆدی داشکاندنی فرۆشگاکان بە ئاگاداری Toast
   - **فەرهەنگی زاراوەکان (Glossary Accordion):** گەڕانی خێرا لە چەمکە تەکنەلۆژییەکان و شیکردنەوەی ورد
   - **کۆمەڵگەی پرسیار و وەڵام (Q&A):** فۆڕمی پرسیار، دەنگدان (Upvotes)، دیاریکردنی وەڵامی چارەسەرکراو، پاڵاوتن بەپێی شارەکانی هەرێم
   - **ڕاوێژکاری کڕین (Smart Advisor):** چوارچێوەیەکی پرسیار و وەڵامی زیرەک بۆ دۆزینەوەی گونجاوترین ئامێر لە بازاڕدا بە نمرەی گونجاوی (Match %)
   - **خوێنەری دەنگی (AI Voice Player):** پەخشی کورتەی دەنگی بابەت بە زمانی کوردی
   - **قەبارەی فۆنت (Font Scaler):** گۆڕینی قەبارەی فۆنتی کوردی (ئاسایی، مامناوەند، گەورە)
   - **پاشەکەوتکردن (Bookmarks):** پاراستنی بابەتە دڵخوازەکان لەناو `localStorage`
   - **مێژووی خوێندنەوە (Reading History):** تۆمارکردنی خۆکارانەی ئەو بابەتانەی خوێندووتیانەتەوە
   - **بەسوود بوو (Likes):** کارلێکی دەستبەجێ لەگەڵ بابەتەکان
   - **سەرنج و لێدوان (Comments):** فۆڕمی زیادکردنی سەرنج لەسەر هەموو بابەتێک
   - **گەڕانی بەپەلە (Spotlight Search):** داگرتنی `Ctrl+K` بۆ گەڕانی خێرا لە هەواڵ و نرخی ئامێرەکان و بەستەرە کورتکراوەکان
   - **ئاگاداری (Toast Notifications):** پەیامی شیک لە کاتی کۆپیکردنی بەستەر یان پاشەکەوتکردن
   - **حاسیبەی دۆلار و دینار:** گۆڕینی ڕاستەوخۆی نرخی ئاڵوگۆڕی دراو بەپێی ڕۆژ

3. **ئەی پی ئای و بزوێنەری گەڕان (APIs & SEO):**
   - `GET /api/articles?category=...&q=...&limit=...`
   - `GET /api/prices?category=...&brand=...&rate=...`
   - `POST /api/comments`
   - خۆکار دروستبوونی `/sitemap.xml` و `/robots.txt` بۆ گەیشتن بە لوتکەی ئەنجامەکانی گووگڵ

## 🛠 دامەزراندن و کارپێکردن

```bash
# دابەزاندنی پێداویستییەکان
npm install

# دەستپێکردنی سێرڤەری گەشەپێدان
npm run dev
```

پەڕەکە لەسەر ناونیشانی [http://localhost:3000](http://localhost:3000) بکەرەوە.
